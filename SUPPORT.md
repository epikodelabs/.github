# Support

## Usage questions

Use GitHub Discussions for:

- usage questions;
- API design questions;
- examples and experiments;
- interoperability ideas;
- feedback about confusing behavior;
- early-stage feature ideas.

## Bug reports

Open an issue when you have a concrete problem that appears to be a defect.

Please include:

- the package and version;
- environment details when relevant;
- a minimal reproduction;
- expected behavior;
- actual behavior;
- error output or stack traces when useful.

## Feature requests

Feature requests are welcome.

For substantial new APIs or architectural changes, start a Discussion first so the direction can be agreed before implementation.

## Security

Do not use public support channels for security vulnerabilities. See [SECURITY.md](SECURITY.md).

## Commercial support

EpikodeLabs projects are primarily maintained as open-source software. Unless a specific project states otherwise, there is no guaranteed response time or service-level agreement.
